## 📲 Panduan Pemasangan

### Di Android TV / Smart TV:
1. Unduh file **APK TV** melalui browser TV atau transfer via Flashdisk / aplikasi *Send Files to TV*.
2. Buka File Manager di TV Anda dan klik file APK yang telah diunduh.
3. Izinkan *"Install apps from unknown sources"* (jika diminta), lalu pilih **Instal**.

### Di Smartphone Android:
1. Unduh file **APK HP** langsung dari browser ponsel Anda.
2. Buka notifikasi unduhan atau file manager, lalu ketuk file APK.
3. Pilih **Instal** dan nikmati streaming film favorit Anda.
